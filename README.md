An interactive, high-performance Image Gallery web application built during my Frontend Development Internship at **CodeAlpha**. Styled using **Tailwind CSS** for clean, utility-first UI architecture, fluid responsive grids, smooth hover transitions, category-based image filtering, and a full-screen lightbox preview.

---

## ⚡ Task Features & Highlights

- **Tailwind CSS Utility Design:** Built entirely using Tailwind's flexible utility classes for modern spacing, colors, typography, and layout controls.
- **Dynamic Category Filtering:** Filter gallery items seamlessly across categories with instant UI feedback and state management.
- **Lightbox Overlay / Preview Modal:** Interactive lightbox modal to view full-resolution images with smooth backdrop blur and focus.
- **Responsive Tailwind Grid:** Custom responsive breakpoints (`sm`, `md`, `lg`, `xl`) ensuring a pixel-perfect masonry/grid layout on all device viewports.
- **Sleek Hover & Transition Effects:** Tailwind transition and transform classes for scale-up hover effects, image zoom, and dynamic overlays.

## ⚙️ Local Setup & Execution

To run and test this Tailwind CSS gallery project locally:

### Prerequisites
Ensure you have **Node.js** (v16+ recommended) and **npm** installed on your system.

### Steps
1. **Clone the repository:**
   ```bash
   git clone [https://github.com/sarmad-tabassum/image-gallery-task-codealpha.git](https://github.com/sarmad-tabassum/image-gallery-task-codealpha.git)
Navigate to the project directory:

Bash
cd image-gallery-task-codealpha
Install project dependencies:

Bash
npm install
Start the local development server:

Bash
npm run dev
Open your browser and navigate to the local server URL (e.g., http://localhost:5173).
